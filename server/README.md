# Digikids API Server

Express.js API for Digikids. Uses Supabase for data and Cloudinary for image uploads.

## Setup

1) Install dependencies
```
npm install
```

2) Create `.env` from `.env.example` and fill values.

3) Apply SQL schema in `sql/schema.sql` to your Supabase database.

## Run

```
npm run dev
```

Server runs on `http://localhost:5050` by default.
